# Triangulated Intelligence Engine

This repository contains the manifest and operational blueprint for the Triangulated Intelligence Engine (TIE), a token-resonance orchestration stack for high-clearance recruitment and consciousness-stream experiences.

## Repository Structure
- `engine_soul/triangulated_intelligence_engine.yaml` – Core manifest describing engine modules, self-augmentation layers, runtime, and deployment flow.
- `docs/launch-readiness.md` – Launch readiness checklist covering productization, API hardening, streaming experience, operations, and go-to-market items.
- `src/components/model-orchestrator/` – Standalone Angular component blueprint for the model orchestration console, including resonance specs, monetization preferences, and Pendo experience telemetry overlays.
- `docs/pendo-integration.md` – Guide for activating the pseudo→real Pendo insight stream across the orchestration stack.

## Getting Started
1. Follow the installation steps in the manifest (`wsl`, `nvm`, Node.js, Codex CLI).
2. Run `codex run engine_soul/triangulated_intelligence_engine.yaml` to boot the orchestration stack.
3. Review the launch readiness checklist to plan the remaining milestones before offering the platform as a commercial API or stream service.
